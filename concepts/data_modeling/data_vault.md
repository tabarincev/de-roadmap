# Что такое Data Vault ?
`Data Vault` — это методология моделирования корпоративных хранилищ данных, предназначенная для работы с постоянно меняющимися данными. Она была разработана Дэном Линстедтом в начале 2000-х годов и преобразована в Data Vault 2.0, в которой добавлены хэш-ключи, шаблоны параллельной загрузки и улучшена интеграция с современными инструментами

# Компоненты

## Hub
Хаб представляет собой уникальную бизнес-концепцию - клиента, продукт, заказ, сотрудника, учетную запись.  В нем хранится только информация, необходимая для уникальной идентификации этой концепции во всех исходных системах. В `Hub` есть следующие столбцы:

| **Колонка** | **Назначение** |
|:--------|:-----------|
| `hash_key (PK)` | Используется в качестве первичного ключа для быстрого объединения |
| `business_key` | Естественный ключ из исходной системы (например, идентификатор клиента, артикул товара) |
| `load_date` | Когда этот бизнес-ключ впервые был обнаружен в DWH |
| `record_source` | Какая исходная система первой предоставила этот ключ |

**Пример:**

| **customer_hash_key** | **customer_bk** | **load_date** | **record_source** |
|:------------------|:------------|:----------|:--------------|
| a3f8c1...	| CUST-10042	| 2024-01-15	| CRM_SALESFORCE |
| b7d2e9...	| CUST-20118	| 2024-01-15	| ERP_SAP |
| c1a4f6...	| CUST-30205	| 2024-02-01	| PARTNER_FEED |
| d8b3a7...	| CUST-40891	| 2024-03-15	| CRM_SALESFORCE |


# Изменения в Data Vault 2.0
> В исходной версии Data Vault (1.0) использовались суррогатные ключи, сгенерированные на основе последовательностей, как и в традиционном многомерном моделировании. Это создавало узкое место: требовался централизованный генератор ключей, а значит, данные нужно было сериализовать

**В Data Vault 2.0 внесено несколько улучшений:**
- **Hash keys** вместо последовательностей - обеспечивает параллельную загрузку
- **Hash diff** для обнаружения изменений - предотвращает дублирование строк в `Satellite`
- **Стандартизированные соглашения об именовании** - префиксы `hub_`, `link_`, `sat_`
- **Business Data Vault** как формальный уровень для бизнес-правил
